$ nc -w 4 api.lan.vdh-ict.nl 22 </dev/null | head -1
  api.lan.vdh-ict.nl     -> SSH-2.0-OpenSSH_10.3
$ nc -w 4 172.16.2.200 22 </dev/null | head -1      # control, by IP
  172.16.2.200           -> SSH-2.0-OpenSSH_10.3

  => Both new names carry a real TCP session to the Mac Studio and return the
     Studio's own SSH banner, byte-identical to the by-IP control. Name ->
     UDM resolver -> 172.16.2.200 -> TCP handshake -> application payload
     from the intended host. This is a genuine end-to-end path proof, not a
     config read-back.
