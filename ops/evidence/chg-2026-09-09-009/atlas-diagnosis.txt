== THE ACTUAL CAUSE: the condition is "darker than ~1 lux" ==
condition: numeric_state, sensor.brandpad_licht, attribute light_level, below 55.

Hue scale: light_level = 10000*log10(lux) + 1, so lux = 10^((level-1)/10000).
  level    55  ->  ~1.01 lux   <- THE THRESHOLD. Near-total darkness.
  level  7221  ->  ~5.3  lux
  level 16464  ->  ~44   lux
  level 42788  ->  ~19000 lux

So anyone crossing the path at dusk gets no light. It looks dark to them and
reads 7221 to the sensor. As evenings draw in this will feel increasingly
broken while behaving exactly as written.

Today's nine motion events were ALL in daylight — 08:17, 08:19, 08:30, 09:23,
10:06, 15:59, 17:25, 17:25, 18:54 local — the last one 76 min before the

== SECONDARY CONSTRAINT ==
sensor.brandpad_licht reports only every ~15 min, so it stepped 7221 -> 0 with
nothing between. There is no gradual arming; the threshold crossing is quantised
to a quarter of an hour. Any new threshold inherits that floor.
